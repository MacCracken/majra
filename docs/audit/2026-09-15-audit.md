# P(-1) Hardening Audit — 2026-09-15 (shipped as 2.8.1)

Third P(-1) pass, run against the 2.8.0 tag. Scope: every module in `src/`, the test suites, hot-path performance, cross-module locking and memory ownership, and external research on the wire protocols (RESP, PostgreSQL v3, RFC 6455, HTTP/1.1) and on the crypto usage (AES-256-GCM, Ed25519).

## Headline result

- **130 findings** after de-duplication (142 raw): **3 critical, 17 high, 48 medium, 62 low**.
- Outcome: 78 fixed, 17 fixed in part, 27 closed with a test only (coverage gaps or pinning, with no code defect behind them), 5 deferred to 2.9.0 because the fix needs an API or wire change, 2 doc corrections, and 1 left open on the roadmap.
- ⚠ **No finding was refuted.** Every deduplicated finding was confirmed by its verifier, which is an unusually high rate and a reason to read the confirmations sceptically. What backs them is the tests: of 108 new regression assertions, 98 were mutation-checked to fail without their fix, and the rest pin coverage.
- The wire format is unchanged. A 2.8.0 ↔ 2.8.1 encrypted-IPC interop probe (separate processes, both roles, both directions) passes all four pairings.

## Deferred to 2.9.0 (API or wire change)

- **[high] Replay protection is per-handle only: frames captured from one connection replay into any later connection under the same PSK** — `src/ipc_encrypted.cyr:375`.
- **[medium] _ws_accept_upgrade discards the request, so no consumer can check Origin: cross-site WebSocket hijacking cannot be prevented** — `src/ws.cyr:449`.
- **[low] Every status sweep bump-allocates its returned transitions vec, even with no transitions, and nothing can release it or its 16-byte pairs** — `src/heartbeat.cyr:186`.
- **[low] Signed bytes carry no domain-separation or version prefix, so envelope signatures can be confused with other Ed25519 uses of the same key** — `src/signed_envelope.cyr:56`.
- **[low] _ws_accept_upgrade completes the handshake with no Origin check (CSWSH) and reads the request one byte at a time with no idle timeout (slowloris)** — `src/ws.cyr:449`.
- Also deferred for the same reason (partial fixes above): delivered-RelayMessage ownership and `relay_unsubscribe`; `pg_rows_free` / `redis_reply_free` for returned result vecs; a distinct error code for a same-role encrypted-IPC frame.

## Found while finishing the pass

- **Test binaries could exit 0 on failure.** Every entry point ended with `syscall(SYS_EXIT, r)`, which ends only the main thread; with detached threads alive the process reported another thread's status, and CI checks exit codes. All entry points now end with `sys_exit_group(r)`; a mutated patra-queue run now exits 4.
- **patra_queue: completing a job also completed its undelivered duplicate-id sibling** on pre-2.8.1 files (`_pq_update_status` matched on id only). Now `AND status = 1`; regression assertion added and mutation-checked.
- **CI syscall gate** would have failed on the sweep's routed `_SYS_SHUTDOWN = 48`, and the new per-arch `_IPC_SYS_SENDTO` evaded its pattern by name. The gate now matches any `*SYS_` var and allows exactly those rows.

## Method

Nine module units (foundation · ratelimit+heartbeat · queues · pubsub+relay · barrier+dag · ipc · fleet+admin · db backends · ws), each reviewed for correctness and security together, plus test-suite, performance, concurrency/memory-ownership and two research lenses. One adversarial verifier per unit batch, and a second, independent one for critical/high findings; both had to agree. One fixer per unit, each owning only its files; test writers ran one suite at a time with mutation checks. The orchestrated part used 49 agents (cap 75). The regression review and this report were finished by hand after the run hit the session limit.
